Visual Synth v0.1.030 - enabled-only routing and synthesis recovery feedback

- SOURCE / ROUTING offers only INPUT CHANNELS that are switched ON.
- Turning a channel OFF disconnects it from all visual tracks; no automatic substitution.
- A NONE option is available for both A and B.
- Source-routing warnings explain no input, zero drive/level, muted sends, identical-signal cancellation, and potential MASK disappearance.
- RESET TRACK also disables Track Combination when that combination involves the track, so it cannot keep masking a reset image.
- No changes to the established fader/knob/panel CSS or the audio analysis worker algorithms.
- Both files are required for GitHub Pages.
